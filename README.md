# computational-ontology.com

Public website of **Computational Ontology** — *the ontological systematization of social, real and ideal objects*.

Single static page (no build step, no framework), served by GitHub Pages at
[computational-ontology.com](https://computational-ontology.com).

## The two-tier rule

**Exploratory use is open** — anyone may apply the published codebook and rubrics to read
cases, teach, or probe the model. **Canonical diagnosis is not**: a structural signature
counts as canonical only when produced by **two trained human coders under the
δ-protocol**. AI-assisted extraction may propose values; only human coders validate them.
